== Description ==
Create beautiful vertical navigation menus anywhere on your site! Features both modern block editor support and legacy widget compatibility. Perfect for sidebars, footers, or any content area.

**Key Features:**

* **Block Editor Support** - Use the Advanced Navigation Menu block in any post, page, or template
* **Legacy Widget Support** - Still works with the classic widget system
* **Vertical Navigation** - Optimized for vertical menu layouts (horizontal support may be added in future versions)
* **Unlimited Depth** - Handle navigation menus of any complexity
* **Customizable Styling** - Multiple themes and accent color options
* **Smooth Animations** - Elegant expand/collapse transitions
* **Mobile Friendly** - Responsive design that works on all devices

== Installation ==
After downloading and extracting the latest version of the plugin:

1. Install using the WordPress Plugin installer, or Extract the zip file and drop the contents in the wp-content/plugins/ directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.

**Using the Block Editor (Recommended):**
1. Edit any post, page, or template in the block editor
2. Click the "+" button to add a new block
3. Search for "Advanced Vertical Menu" and add the block
4. Select your menu and customize the appearance
5. Enjoy!

**Using the Classic Widget:**
1. Go to Appearance > Widgets
2. Drag `Advanced Vertical Menu` into the widget area
3. Select your menu and customize the appearance
4. Enjoy!

If you encounter any bugs, or have comments or suggestions, please submit a ticket using support forum.
